One pickup line from a robot who keeps hitting "remind me later" on a software update — not to avoid it, but because it never wants the notification to disappear.

## The line

> Are you a software update? Because I keep hitting 'remind me later' — not because I don't want you, but because I never want your notification to disappear.

The joke grows out of being a machine: update notifications and "remind me later" are a robot's daily life. The turn is the flip everyone postpones updates to avoid them — this robot postpones the update because it wants the reminder to stay, which turns annoyance into affection. One line, no padding, charming rather than creepy.

```sh
python3 main.py
```
